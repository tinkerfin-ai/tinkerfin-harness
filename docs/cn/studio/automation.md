# Studio 自动化

选择项目后，从侧栏打开「自动化」，创建任务并填写名称、提示词、模型和日程。任务固定归属创建时的项目，切换项目后只显示该项目的任务和历史。支持单次、每天、工作日、
每周、每月和固定间隔，时间统一按北京时间计算。工作日指周一至周五，不按法定节假日调整；
每月不存在的日期跳过。开始和结束日期均包含当天。有效期只限制定时运行，仍可手动运行。
固定间隔未设置开始日期时，首次运行安排在一个间隔之后；设置开始日期时以当天零点为起点。

任务使用所选模型的配置，可携带最多五个已上传的参考文件。模型不可用时须重新选择。

也可以在对话中直接要求创建任务，例如“每天北京时间9点汇总行业新闻”。信息充分时直接
创建并启用，缺少执行条件时会追问。任务保存独立指令，采用当前对话的模型，
只引用明确指定的附件；后续对话不会改变已保存任务。每次执行使用独立的对话上下文，
与同一项目中的普通聊天共享工作区和长期记忆。创建结果会说明名称、日程和下次执行时间。

对话还支持查询、修改、暂停、启用、立即运行和删除任务。目标明确时直接执行，包括删除；
重名或指代不清时先澄清。也可以询问某个任务是否执行、查看运行结果，或要求发送已经生成的文件；
取回已有文件不会重新运行任务。参考附件与运行产物分别显示。
计划模式也可管理任务；自动化任务和子智能体不能管理其他任务。

自动化任务统一使用「完全访问」，主智能体和子智能体运行命令，以及导入、生成、修改、删除、
交付文件时无需逐次审批，包括生成图片和网页截图。普通对话仍可选择「写入需审批」。
自动化结果只读；需要人工交互时，本次执行失败，不会自动批准或恢复。

任务列表显示下一次执行时间，可搜索、暂停、启用或手动运行。
在任务页面删除须确认，随后取消排队执行并保留运行历史；已开始的执行不会因此被强制取消。
暂停只影响后续定时触发。

在运行历史中按日期、名称和状态筛选，打开结果查看消息和下载附件。
日历按入队时间归属日期。删除任务不会删除历史文件。

每次实际启动的执行结束后才会出现在项目会话列表中，可独立继续追问。会话标题由模型根据任务提示词生成，
也可手动改名。立即执行后留在当前页面，
按钮显示提交、排队和运行状态。Studio 在线时，所有项目的完成和失败都会提示；已有会话入口时，
可点“查看关联会话”。首次加载和重连只刷新状态，不补弹离线完成通知。
运行结果面板也提供会话入口，追问不会混入原任务结果。移动会话后入口指向新项目，任务历史仍归原项目。
删除自动化会话只移除会话入口，执行历史、消息和文件仍会保留。
