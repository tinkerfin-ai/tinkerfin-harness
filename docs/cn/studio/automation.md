# Studio 自动化

从侧栏打开「自动化」，创建任务并填写名称、提示词、模型和日程。支持单次、每天、工作日、
每周、每月和固定间隔，时间统一按北京时间计算。工作日指周一至周五，不按法定节假日调整；
每月不存在的日期跳过。开始和结束日期均包含当天。有效期只限制定时运行，仍可手动运行。

任务使用所选模型的配置，可携带最多五个已上传的参考文件。模型不可用时须重新选择。

对话和任务的权限默认都是「完全访问」（`full`）。「写入需审批」（`write_approval`）
启用主智能体及子智能体的 `write_file` 审批；此选项不是沙箱只读策略。
对话运行期间不能更改权限，恢复或分支沿用来源运行的权限。
自动化结果只读：需要人工审批或其他人工交互时，本次执行失败，不会自动批准或恢复。

任务列表显示下一次执行时间，可搜索、暂停、启用或手动运行。
删除须确认，随后取消排队执行并保留运行历史；已开始的执行不会因此被强制取消。
暂停只影响后续定时触发。

在运行历史中按日期、名称和状态筛选，打开结果查看消息和下载附件。
日历按入队时间归属日期。删除任务不会删除历史文件。
