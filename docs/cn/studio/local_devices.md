# 在 Mac 上执行本地任务

[Studio 上手指南](quick_start.md) · [English](../../en/studio/local_devices.md)

TinkerFin 客户端让 Studio 会话使用 Mac 上的文件、Python、Node、独立浏览器和 MCP 工具。对话由云端 Agent 处理，客户端执行本机工具；模型密钥保留在云端。

## 连接

1. 从 [GitHub Releases](https://github.com/tinkerfin-ai/tinkerfin-harness/releases) 下载客户端，在 Apple Silicon Mac（macOS 15+）上解压并打开。应用未通过 Apple 公证，打开方法见[安装说明](../../../apps/desktop/README.md#安装与连接)。
2. 点击菜单栏图标，选择“连接”，填写 Studio 地址，再在浏览器登录自己的 Studio 账号并授权。看到授权成功后可关闭页面，从菜单栏打开客户端。
3. 客户端显示“已连接”后，在 Studio 选择项目，再点击顶部的本地图标发起会话。

项目工作区由客户端自动创建，无需选择目录。设备在“设置 → 本地设备”中管理；连接过设备后，顶部显示本地图标，绿点表示已连接，红点表示未连接。

同一账号只保留一台有效设备；新授权会使原设备的配对失效，已有本地会话的新消息使用当前设备。待审批操作保留原授权，不会自动转到另一台设备。在客户端“设置”中点击设备名称编辑，按 Enter 或离开输入框自动保存；“切换”可更换账号。

在客户端“设置 → 语言”选择“跟随系统”“简体中文”或“English”，切换立即生效，并在下次启动时保留。

## 项目与文件

本地工作区保存在 `~/.tinkerfin/projects/`，按 Studio 服务、账号及项目身份分别隔离。云端保存项目与账号的归属；项目改名或同一账号重新连接不会改变本地目录。切换账号保留原目录，切回后继续使用。更换电脑不会自动传输原电脑上的文件。

云端与本地的项目文件相互独立。任务可导入会话附件；明确交付的结果作为附件回到会话，可查看或下载。本地模式下，顶部工作区按钮打开客户端中的项目目录。

项目目录是任务的默认工作目录。可以直接指定本机绝对路径或 `~/` 路径处理其他位置的文件；相对路径从项目目录解析，无需逐个目录授权。客户端配置、任务状态、凭证和其他账号或项目的托管目录仍受保护，系统权限也继续生效。

已开始的会话保持原执行位置，本地会话不能移动到其他项目。需要更换位置或项目时，在目标项目中新建会话，再选择云端或本地。新会话中切换位置保留文字草稿，附件重新核验；无法继续使用的引用需重新添加。新会话沿用该项目最后明确选择的位置。

## 权限与恢复

“完全访问”和“写入需审批”可访问相同的本机文件范围。选择“写入需审批”后，命令、文件修改及浏览器、MCP 操作会在会话中请求审批。云端与本地使用相同的对话界面：审批在输入区处理，结果回到对话，“停止任务”按钮请求停止当前执行。关闭网页不代表本机工具已经停止。设备短暂断线后，重新连接会继续同步已受理操作；设备持续离线导致请求失败时，先重新连接，再检查结果。

网页任务使用独立的可见浏览器，页面跨工具调用、对话轮次和短暂断线保留。客户端优先使用可用的系统 Chrome，没有时自动准备浏览器。网站登录按 Studio 账号、项目和会话分别保存，不读取日常浏览器资料；换账号会关闭原账号的浏览器，登录资料仍保留。停止浏览器操作会关闭当前会话的浏览器，保留登录资料。普通网页操作和网页截图无需辅助功能或屏幕录制权限；只打开链接时使用系统默认浏览器。

读取其他应用的控件、点击与输入需要辅助功能权限，截取其窗口还需要屏幕录制权限，可在客户端“设置 → 桌面权限”管理。窗口内容和截图会经 Studio 交给所选模型。桌面应用使用自身权限，不受文件与命令工具的沙箱规则约束。

普通联网无需配置域名。工具权限从本机配置读取，MCP 仅运行已配置的程序。客户端的“设置 → 配置文件”可打开 `~/.tinkerfin/settings.json`，模型密钥不写入该文件。

停止或撤销授权不能撤回已发生的操作。离线任务或显示“操作结果待核验”的任务，需先核验文件与应用状态，再决定是否重做；系统不会自动重做结果不确定的操作。

安装、构建、数据位置与卸载见[客户端说明](../../../apps/desktop/README.md)。
