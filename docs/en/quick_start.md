# Quick Start

[Documentation](index.md) · [中文](../cn/quick_start.md)

## Try the workspace

Use Studio to chat, upload attachments, review plans, and inspect execution.
You need Docker, Docker Compose, Node.js, and access to a model provider.

[Set up Studio →](studio/quick_start.md)

## Build an agent application

Create an agent in Python and consume its output. Add a frontend or persistence when you need them.
You need Python 3.11+ and model provider credentials.

[Run your first agent →](runtime/quick_start.md)
